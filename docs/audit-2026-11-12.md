# Audit ulang, 12 November 2026

## Masalah yang diperbaiki

- Status simpan editor sebelumnya memakai timer tanpa memeriksa server. Sekarang status mengikuti respons HTTP, menampilkan kegagalan dan tombol coba lagi.
- Draft kosong dan reset ke starter sebelumnya dilewatkan. Keduanya sekarang disimpan; draft kosong yang sudah tersimpan tidak diganti dengan starter saat membuka materi.
- Permintaan simpan diserialkan agar respons lambat tidak menyebabkan kode lama menimpa kode terbaru. Perubahan terakhir di-flush saat meninggalkan materi; kegagalan koneksi tetap dapat menghalangi penyimpanan.
- Shortcut Monaco sebelumnya menangkap callback awal. Shortcut sekarang memanggil handler terbaru dan menghormati status eksekusi.
- XP bernilai nol sebelumnya berubah menjadi 20 karena fallback `||`. Sekarang nol dipertahankan.
- Respons gagal dari API submission sekarang menjadi pesan error, bukan dianggap jawaban salah. Console beralih ke tab yang menampilkan pesan tersebut.
- Header XP diperbarui dari XP yang diberikan API, meski respons tidak menyertakan `userStats`.
- Persentase course hanya menghitung materi course tersebut.
- Cerita Python dibatasi pada course Python Fundamental, sehingga slug sama pada course lain tidak menampilkan cerita yang salah.
- Detail status editor dipadatkan pada panel sempit agar status simpan tidak tertutup.

## Temuan backend yang belum diselesaikan

**Prioritas tinggi: penilaian belum tepercaya di server.** `app/api/submissions/route.ts` menerima `status` dari klien lalu memberikan XP dan kelulusan. Pengguna yang mengubah request dapat mengaku lulus. Perbaikan menyeluruh membutuhkan eksekusi atau verifikasi jawaban di lingkungan terisolasi sisi server, bukan sekadar membandingkan output yang juga dikirim klien. Audit ini tidak menambahkan eksekusi Python tak terisolasi ke server.

**Keterbatasan evaluator saat ini:** test case dijalankan dengan satu hasil output; input masing-masing test case belum diterapkan. Materi bawaan yang diperiksa memakai latihan output tanpa input, tetapi CMS tidak boleh dianggap mendukung evaluasi input berbeda sebelum evaluator diperbarui.

Cerita kurasi berada di source, bukan CMS. Setelah isi konsep di CMS diubah, cerita terkait perlu diperiksa agar tetap sesuai.

## Pemeriksaan

TypeScript, tes unit untuk cerita/Markdown/penyimpanan, ESLint terarah, dan build produksi webpack. Uji browser tambahan memakai respons API simulasi untuk tidak mengubah draft, XP, dan kelulusan akun demo. Lint seluruh repository memiliki temuan lama dan tidak dinyatakan bersih.

## Hasil akhir pengujian ulang

- 7 tes unit lulus: empat pengujian cerita/Markdown dan tiga pengujian simpan draft (kosong/reset, urutan request, gagal/coba lagi).
- TypeScript, ESLint untuk komponen cerita/editor dan penyimpan draft, serta `git diff --check` lulus.
- Build produksi webpack berhasil setelah perbaikan.
- Uji browser regresi terbaru belum dapat diselesaikan: koneksi Turso menghasilkan `UND_ERR_CONNECT_TIMEOUT` / `UND_ERR_SOCKET` dan login HTTP 500. Karena itu, shortcut dan alur submission terbaru belum dinyatakan lulus pengujian browser. Hasil UI pada audit sebelumnya tidak digunakan sebagai pengganti uji regresi ini.
